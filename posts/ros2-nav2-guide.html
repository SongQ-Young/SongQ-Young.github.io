ROS2 Navigation Stack深度解析

📅 2024-10-30 ✍️ SongQ-Young 🏷️ 导航框架
ROS2 导航 框架

1. 引言

ROS2 Navigation Stack（Nav2）是ROS2生态系统中用于移动机器人自主导航的核心框架。相比ROS1的导航栈，Nav2在架构设计、插件系统、行为树集成等方面进行了全面升级。本文将深入解析Nav2的架构设计、核心组件、插件开发以及实战应用，帮助开发者快速掌握Nav2的使用和定制。

Nav2基于行为树（Behavior Tree）架构，提供了高度模块化和可扩展的导航能力。无论是简单的点到点导航，还是复杂的多目标任务规划，Nav2都能提供强大的支持。

2. Nav2架构概览

2.1 核心组件

Nav2由多个功能模块组成，每个模块负责特定的导航任务：

  • BT Navigator: 基于行为树的任务管理器，协调各个导航模块
  • Planner Server: 全局路径规划服务，生成从起点到终点的全局路径
  • Controller Server: 局部路径跟踪控制器，实时跟踪全局路径
  • Recovery Server: 恢复行为管理器，处理机器人被困等异常情况
  • Waypoint Follower: 路点跟随器，支持多目标点导航
  • Lifecycle Manager: 生命周期管理器，管理所有导航节点的启动和关闭
  • AMCL: 自适应蒙特卡洛定位算法，用于机器人定位
  • Map Server: 地图服务器，提供静态地图数据
  • Costmap 2D: 代价地图生成器，融合多种传感器数据

3. 行为树（Behavior Tree）

3.1 行为树基础

Nav2使用BehaviorTree.CPP库实现行为树功能。行为树是一种层次化的任务控制结构，由不同类型的节点组成：

  • Action节点: 执行具体动作（如规划路径、移动机器人）
  • Condition节点: 判断条件（如目标是否到达、路径是否有效）
  • Control节点: 控制执行流程（Sequence、Fallback、Parallel等）
  • Decorator节点: 修饰子节点行为（如重试、超时控制）

3.2 默认导航行为树

Nav2提供了一个默认的导航行为树，实现了基本的导航流程： 

<!-- navigate_to_pose_w_replanning.xml -->
<root main_tree_to_execute="MainTree">
    <BehaviorTree ID="MainTree">
        <RecoveryNode number_of_retries="6" name="NavigateRecovery">
            <PipelineSequence name="NavigateWithReplanning">
                <RateController hz="1.0">
                    <RecoveryNode number_of_retries="1" name="ComputePathToPose">
                        <ComputePathToPose goal="{goal}" path="{path}" planner_id="GridBased"/>
                        <ClearEntireCostmap name="ClearGlobalCostmap-Context" service_name="global_costmap/clear_entirely_global_costmap"/>
                    </RecoveryNode>
                </RateController>
                <RecoveryNode number_of_retries="1" name="FollowPath">
                    <FollowPath path="{path}" controller_id="FollowPath"/>
                    <ClearEntireCostmap name="ClearLocalCostmap-Context" service_name="local_costmap/clear_entirely_local_costmap"/>
                </RecoveryNode>
            </PipelineSequence>
            <RecoversSequence>
                <ClearEntireCostmap name="ClearLocalCostmap-Recovery" service_name="local_costmap/clear_entirely_local_costmap"/>
                <ClearEntireCostmap name="ClearGlobalCostmap-Recovery" service_name="global_costmap/clear_entirely_global_costmap"/>
                <Spin spin_dist="1.57"/>
                <Wait wait_duration="5"/>
                <BackUp backup_dist="0.30" backup_speed="0.05"/>
            </RecoversSequence>
        </RecoveryNode>
    </BehaviorTree>
</root>

    // 执行自定义逻辑

    std::string result = "处理结果: " + input;
    setOutput("output_result", result);

    return BT::NodeStatus::SUCCESS;
  }

  void halt() override
  {
    RCLCPP_INFO(node_->get_logger(), "中止自定义动作");
  }

private:
  rclcpp::Node::SharedPtr node_;
};

}  // namespace custom_bt_nodes

4. 全局路径规划器

4.1 内置规划器

Nav2提供了多种全局路径规划算法：

  • NavFn Planner: 基于Dijkstra或A*算法的规划器
  • Smac Planner: 基于State Lattice的混合A*规划器，支持多种运动模型
  • Theta* Planner: 基于Theta*算法，生成更平滑的路径

4.2 Smac Planner配置

planner_server:
  ros__parameters:

4.3 自定义规划器插件

// custom_planner.hpp
#ifndef CUSTOM_PLANNER_HPP_
#define CUSTOM_PLANNER_HPP_

#include "rclcpp/rclcpp.hpp"
#include "nav2_core/global_planner.hpp"
#include "nav_msgs/msg/path.hpp"
#include "geometry_msgs/msg/pose_stamped.hpp"

namespace custom_planner
{

class CustomPlanner : public nav2_core::GlobalPlanner
{
public:
  CustomPlanner() = default;
  ~CustomPlanner() override = default;

  // 配置插件
  void configure(
    const rclcpp_lifecycle::LifecycleNode::WeakPtr & parent,
    std::string name,
    std::shared_ptr<tf2_ros::Buffer> tf,
    std::shared_ptr<nav2_costmap_2d::Costmap2DROS> costmap_ros) override
  {
    node_ = parent.lock();
    name_ = name;
    tf_ = tf;
    costmap_ros_ = costmap_ros;
    costmap_ = costmap_ros_->getCostmap();

    RCLCPP_INFO(node_->get_logger(), "配置自定义规划器: %s", name_.c_str());

    // 声明和获取参数
    nav2_util::declare_parameter_if_not_declared(
      node_, name_ + ".interpolation_resolution", rclcpp::ParameterValue(0.1));
    node_->get_parameter(name_ + ".interpolation_resolution", interpolation_resolution_);
  }

  // 激活插件
  void activate() override
  {
    RCLCPP_INFO(node_->get_logger(), "激活自定义规划器");
  }

  // 失活插件
  void deactivate() override
  {
    RCLCPP_INFO(node_->get_logger(), "失活自定义规划器");
  }

  // 清理插件
  void cleanup() override
  {
    RCLCPP_INFO(node_->get_logger(), "清理自定义规划器");
  }

  // 创建规划路径
  nav_msgs::msg::Path createPlan(
    const geometry_msgs::msg::PoseStamped & start,
    const geometry_msgs::msg::PoseStamped & goal) override
  {
    RCLCPP_INFO(node_->get_logger(), "开始规划路径");

    nav_msgs::msg::Path path;
    path.header.frame_id = costmap_ros_->getGlobalFrameID();
    path.header.stamp = node_->now();

    // 实现自定义规划算法
    // 这里以直线插值为简单示例
    double dx = goal.pose.position.x - start.pose.position.x;
    double dy = goal.pose.position.y - start.pose.position.y;
    double distance = std::hypot(dx, dy);
    int num_points = static_cast<int>(distance / interpolation_resolution_);

    for (int i = 0; i <= num_points; ++i) {
      double ratio = static_cast<double>(i) / num_points;
      geometry_msgs::msg::PoseStamped pose;
      pose.header = path.header;
      pose.pose.position.x = start.pose.position.x + dx * ratio;
      pose.pose.position.y = start.pose.position.y + dy * ratio;
      pose.pose.position.z = 0.0;
      pose.pose.orientation = goal.pose.orientation;

      // 检查是否碰撞
      unsigned int mx, my;
      if (costmap_->worldToMap(pose.pose.position.x, pose.pose.position.y, mx, my)) {
        if (costmap_->getCost(mx, my) < nav2_costmap_2d::LETHAL_OBSTACLE) {
          path.poses.push_back(pose);
        } else {
          RCLCPP_WARN(node_->get_logger(), "路径点碰撞障碍物");
          return nav_msgs::msg::Path();  // 返回空路径
        }
      }
    }

    RCLCPP_INFO(node_->get_logger(), "规划完成，路径点数: %zu", path.poses.size());
    return path;
  }

private:
  rclcpp_lifecycle::LifecycleNode::SharedPtr node_;
  std::string name_;
  std::shared_ptr<tf2_ros::Buffer> tf_;
  std::shared_ptr<nav2_costmap_2d::Costmap2DROS> costmap_ros_;
  nav2_costmap_2d::Costmap2D * costmap_;
  double interpolation_resolution_;
};

}  // namespace custom_planner

#endif  // CUSTOM_PLANNER_HPP_

5.3 自定义控制器插件

// custom_controller.hpp
#ifndef CUSTOM_CONTROLLER_HPP_
#define CUSTOM_CONTROLLER_HPP_

#include "rclcpp/rclcpp.hpp"
#include "nav2_core/controller.hpp"
#include "geometry_msgs/msg/twist.hpp"
#include "geometry_msgs/msg/pose_stamped.hpp"
#include "nav_msgs/msg/path.hpp"

namespace custom_controller
{

class CustomController : public nav2_core::Controller
{
public:
  CustomController() = default;
  ~CustomController() override = default;

  void configure(
    const rclcpp_lifecycle::LifecycleNode::WeakPtr & parent,
    std::string name,
    std::shared_ptr<tf2_ros::Buffer> tf,
    std::shared_ptr<nav2_costmap_2d::Costmap2DROS> costmap_ros) override
  {
    node_ = parent.lock();
    name_ = name;
    tf_ = tf;
    costmap_ros_ = costmap_ros;

    // 声明参数
    nav2_util::declare_parameter_if_not_declared(
      node_, name_ + ".max_linear_vel", rclcpp::ParameterValue(0.5));
    nav2_util::declare_parameter_if_not_declared(
      node_, name_ + ".max_angular_vel", rclcpp::ParameterValue(1.0));
    nav2_util::declare_parameter_if_not_declared(
      node_, name_ + ".lookahead_distance", rclcpp::ParameterValue(0.5));

    node_->get_parameter(name_ + ".max_linear_vel", max_linear_vel_);
    node_->get_parameter(name_ + ".max_angular_vel", max_angular_vel_);
    node_->get_parameter(name_ + ".lookahead_distance", lookahead_distance_);

    RCLCPP_INFO(node_->get_logger(), "配置自定义控制器: %s", name_.c_str());
  }

  void activate() override
  {
    RCLCPP_INFO(node_->get_logger(), "激活自定义控制器");
  }

  void deactivate() override
  {
    RCLCPP_INFO(node_->get_logger(), "失活自定义控制器");
  }

  void cleanup() override
  {
    RCLCPP_INFO(node_->get_logger(), "清理自定义控制器");
  }

  void setPlan(const nav_msgs::msg::Path & path) override
  {
    global_plan_ = path;
  }

  geometry_msgs::msg::TwistStamped computeVelocityCommands(
    const geometry_msgs::msg::PoseStamped & pose,
    const geometry_msgs::msg::Twist & velocity,
    nav2_core::GoalChecker * goal_checker) override
  {
    geometry_msgs::msg::TwistStamped cmd_vel;
    cmd_vel.header.frame_id = pose.header.frame_id;
    cmd_vel.header.stamp = node_->now();

    if (global_plan_.poses.empty()) {
      RCLCPP_WARN(node_->get_logger(), "全局路径为空");
      return cmd_vel;
    }

    // 寻找前视点
    geometry_msgs::msg::PoseStamped lookahead_point = findLookaheadPoint(pose);

    // 计算到前视点的距离和角度
    double dx = lookahead_point.pose.position.x - pose.pose.position.x;
    double dy = lookahead_point.pose.position.y - pose.pose.position.y;
    double distance = std::hypot(dx, dy);

    // 计算目标角度
    double target_angle = std::atan2(dy, dx);

    // 获取当前朝向
    tf2::Quaternion q(
      pose.pose.orientation.x,
      pose.pose.orientation.y,
      pose.pose.orientation.z,
      pose.pose.orientation.w);
    tf2::Matrix3x3 m(q);
    double roll, pitch, yaw;
    m.getRPY(roll, pitch, yaw);

    // 计算角度误差
    double angle_error = angles::shortest_angular_distance(yaw, target_angle);

    // Pure Pursuit控制律
    if (std::abs(angle_error) > 0.1) {
      // 先旋转对准目标
      cmd_vel.twist.linear.x = 0.0;
      cmd_vel.twist.angular.z = std::clamp(
        angle_error * 2.0, -max_angular_vel_, max_angular_vel_);
    } else {
      // 前进
      cmd_vel.twist.linear.x = std::min(max_linear_vel_, distance);
      cmd_vel.twist.angular.z = std::clamp(
        angle_error * 1.0, -max_angular_vel_, max_angular_vel_);
    }

    return cmd_vel;
  }

  void setSpeedLimit(const double & speed_limit, const bool & percentage) override
  {
    if (percentage) {
      max_linear_vel_ = max_linear_vel_ * speed_limit / 100.0;
    } else {
      max_linear_vel_ = speed_limit;
    }
  }

private:
  geometry_msgs::msg::PoseStamped findLookaheadPoint(
    const geometry_msgs::msg::PoseStamped & pose)
  {
    // 在全局路径上寻找距离当前位置lookahead_distance_的点
    double min_dist = std::numeric_limits<double>::max();
    size_t closest_idx = 0;

    for (size_t i = 0; i < global_plan_.poses.size(); ++i) {
      double dx = global_plan_.poses[i].pose.position.x - pose.pose.position.x;
      double dy = global_plan_.poses[i].pose.position.y - pose.pose.position.y;
      double dist = std::hypot(dx, dy);

      if (dist < min_dist) {
        min_dist = dist;
        closest_idx = i;
      }
    }

    // 从最近点开始向前寻找lookahead点
    for (size_t i = closest_idx; i < global_plan_.poses.size(); ++i) {
      double dx = global_plan_.poses[i].pose.position.x - pose.pose.position.x;
      double dy = global_plan_.poses[i].pose.position.y - pose.pose.position.y;
      double dist = std::hypot(dx, dy);

      if (dist >= lookahead_distance_) {
        return global_plan_.poses[i];
      }
    }

    // 如果没找到，返回路径终点
    return global_plan_.poses.back();
  }

  rclcpp_lifecycle::LifecycleNode::SharedPtr node_;
  std::string name_;
  std::shared_ptr<tf2_ros::Buffer> tf_;
  std::shared_ptr<nav2_costmap_2d::Costmap2DROS> costmap_ros_;
  nav_msgs::msg::Path global_plan_;

  double max_linear_vel_;
  double max_angular_vel_;
  double lookahead_distance_;
};

}  // namespace custom_controller

#endif  // CUSTOM_CONTROLLER_HPP_

7.2 Nav2启动配置

# nav2_launch.py
import os
from ament_index_python.packages import get_package_share_directory
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, IncludeLaunchDescription
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node
from nav2_common.launch import RewrittenYaml

def generate_launch_description():
    # 获取包路径
    bringup_dir = get_package_share_directory('nav2_bringup')

    # 声明参数
    namespace = LaunchConfiguration('namespace')
    use_sim_time = LaunchConfiguration('use_sim_time')
    autostart = LaunchConfiguration('autostart')
    params_file = LaunchConfiguration('params_file')
    map_yaml_file = LaunchConfiguration('map')

    # 参数声明
    declare_namespace_cmd = DeclareLaunchArgument(
        'namespace',
        default_value='',
        description='顶层命名空间')

    declare_use_sim_time_cmd = DeclareLaunchArgument(
        'use_sim_time',
        default_value='true',
        description='使用仿真时间')

    declare_autostart_cmd = DeclareLaunchArgument(
        'autostart',
        default_value='true',
        description='自动启动生命周期节点')

    declare_params_file_cmd = DeclareLaunchArgument(
        'params_file',
        default_value=os.path.join(bringup_dir, 'params', 'nav2_params.yaml'),
        description='Nav2参数文件完整路径')

    declare_map_yaml_cmd = DeclareLaunchArgument(
        'map',
        default_value=os.path.join(bringup_dir, 'maps', 'map.yaml'),
        description='地图文件完整路径')

    # Map Server
    start_map_server_cmd = Node(
        package='nav2_map_server',
        executable='map_server',
        name='map_server',
        output='screen',
        parameters=[{'use_sim_time': use_sim_time},
                    {'yaml_filename': map_yaml_file}])

    # AMCL
    start_amcl_cmd = Node(
        package='nav2_amcl',
        executable='amcl',
        name='amcl',
        output='screen',
        parameters=[params_file,
                    {'use_sim_time': use_sim_time}])

    # Controller Server
    start_controller_server_cmd = Node(
        package='nav2_controller',
        executable='controller_server',
        name='controller_server',
        output='screen',
        parameters=[params_file,
                    {'use_sim_time': use_sim_time}])

    # Planner Server
    start_planner_server_cmd = Node(
        package='nav2_planner',
        executable='planner_server',
        name='planner_server',
        output='screen',
        parameters=[params_file,
                    {'use_sim_time': use_sim_time}])

    # Recovery Server
    start_recovery_server_cmd = Node(
        package='nav2_recoveries',
        executable='recoveries_server',
        name='recoveries_server',
        output='screen',
        parameters=[params_file,
                    {'use_sim_time': use_sim_time}])

    # BT Navigator
    start_bt_navigator_cmd = Node(
        package='nav2_bt_navigator',
        executable='bt_navigator',
        name='bt_navigator',
        output='screen',
        parameters=[params_file,
                    {'use_sim_time': use_sim_time}])

    # Waypoint Follower
    start_waypoint_follower_cmd = Node(
        package='nav2_waypoint_follower',
        executable='waypoint_follower',
        name='waypoint_follower',
        output='screen',
        parameters=[params_file,
                    {'use_sim_time': use_sim_time}])

    # Lifecycle Manager
    start_lifecycle_manager_cmd = Node(
        package='nav2_lifecycle_manager',
        executable='lifecycle_manager',
        name='lifecycle_manager_navigation',
        output='screen',
        parameters=[{'use_sim_time': use_sim_time},
                    {'autostart': autostart},
                    {'node_names': ['map_server',
                                    'amcl',
                                    'controller_server',
                                    'planner_server',
                                    'recoveries_server',
                                    'bt_navigator',
                                    'waypoint_follower']}])

    # RViz
    start_rviz_cmd = Node(
        package='rviz2',
        executable='rviz2',
        name='rviz2',
        arguments=['-d', os.path.join(bringup_dir, 'rviz', 'nav2_default_view.rviz')],
        parameters=[{'use_sim_time': use_sim_time}],
        output='screen')

    ld = LaunchDescription()

    # 声明参数
    ld.add_action(declare_namespace_cmd)
    ld.add_action(declare_use_sim_time_cmd)
    ld.add_action(declare_autostart_cmd)
    ld.add_action(declare_params_file_cmd)
    ld.add_action(declare_map_yaml_cmd)

    # 启动节点
    ld.add_action(start_map_server_cmd)
    ld.add_action(start_amcl_cmd)
    ld.add_action(start_controller_server_cmd)
    ld.add_action(start_planner_server_cmd)
    ld.add_action(start_recovery_server_cmd)
    ld.add_action(start_bt_navigator_cmd)
    ld.add_action(start_waypoint_follower_cmd)
    ld.add_action(start_lifecycle_manager_cmd)
    ld.add_action(start_rviz_cmd)

    return ld

9. 性能调优建议

9.1 规划器性能优化

  • 降低地图分辨率: 在保证精度的前提下，使用0.05-0.1m的分辨率
  • 限制规划时间: 设置合理的max_planning_time，避免规划阻塞
  • 使用加权A*: 通过调整启发式权重加快搜索速度
  • 启用路径缓存: 对于静态环境，可以缓存已规划路径

9.2 控制器性能优化

  • 调整控制频率: 根据机器人动力学性能设置合适的控制频率（通常20-50Hz）
  • 速度采样优化: 减少vx_samples和vtheta_samples降低计算量
  • 轨迹仿真时间: sim_time不宜过长，1.0-2.0秒为宜
  • critic权重调整: 根据实际场景调整各个critic的权重

9.3 代价地图优化

  • 更新频率: 全局代价地图1Hz，局部代价地图5-10Hz
  • 地图尺寸: 局部代价地图不宜过大，3x3米到5x5米
  • 传感器融合: 合理配置不同传感器的观测距离和权重
  • 膨胀半径: 根据机器人尺寸设置合适的膨胀半径
