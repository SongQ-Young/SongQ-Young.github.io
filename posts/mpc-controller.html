模型预测控制(MPC)在自主导航中的应用

📅 2024-12-08 ✍️ SongQ-Young 🏷️ 运动控制
运动控制 MPC ROS

1. 引言

模型预测控制(Model Predictive Control, MPC)作为一种先进的控制策略,在自主导航领域展现出卓越的性能。与传统的PID控制器不同,MPC能够显式地处理系统约束、预测未来状态,并优化长期性能指标。本文将深入探讨MPC的理论基础、数学原理以及在移动机器人导航中的实际应用。

MPC的核心思想是在每个控制周期内,求解一个有限时域的开环优化问题。通过滚动优化和反馈校正,MPC能够在满足系统约束的前提下实现最优控制。这使得MPC特别适合处理具有复杂动态特性和多约束的移动机器人系统。

2. MPC基本原理

2.1 预测控制框架

MPC的工作流程包含三个核心步骤:

  • 预测: 基于系统模型预测未来N步的状态轨迹
  • 优化: 求解最优控制序列以最小化代价函数
  • 执行: 仅应用第一个控制输入,然后重复整个过程

2.2 MPC优化问题

标准的MPC问题可以表述为: 

// MPC优化问题的数学表述
minimize: J = Σ(||x_k - x_ref||²_Q + ||u_k||²_R) + ||x_N - x_ref||²_P

subject to:
    x_{k+1} = f(x_k, u_k)           // 系统动态约束
    x_min ≤ x_k ≤ x_max             // 状态约束
    u_min ≤ u_k ≤ u_max             // 控制约束
    Δu_min ≤ u_k - u_{k-1} ≤ Δu_max // 控制变化率约束

其中:
    x_k: k时刻的状态向量
    u_k: k时刻的控制输入
    x_ref: 参考轨迹
    Q, R, P: 权重矩阵
    N: 预测时域长度

2.3 滚动时域策略

MPC采用滚动时域(Receding Horizon)策略,在每个采样时刻重新求解优化问题: 

// 滚动时域MPC伪代码
function MPC_Control(x_current, reference_trajectory):
    while system_running:
        // 1. 状态估计/测量
        x_measured = get_current_state()

        // 2. 求解优化问题
        u_sequence = solve_optimization(
            x_initial = x_measured,
            x_reference = reference_trajectory,
            horizon = N
        )

        // 3. 应用第一个控制输入
        apply_control(u_sequence[0])

        // 4. 等待下一个采样周期
        wait(sampling_time)

        // 5. 滚动时域前进,重复优化

3. 移动机器人状态空间模型

3.1 运动学模型

对于差分驱动机器人,常用的运动学模型为: 

// 差分驱动机器人运动学模型
struct RobotState {
    double x;      // x坐标 (m)
    double y;      // y坐标 (m)
    double theta;  // 航向角 (rad)
    double v;      // 线速度 (m/s)
    double omega;  // 角速度 (rad/s)
};

// 连续时间状态方程
// ẋ = v * cos(θ)
// ẏ = v * sin(θ)
// θ̇ = ω
// v̇ = a
// ω̇ = α

class KinematicModel {
public:
    RobotState predict(const RobotState& state,
                      const ControlInput& u,
                      double dt) {
        RobotState next_state;

        // 使用欧拉积分或龙格库塔法
        next_state.x = state.x + state.v * cos(state.theta) * dt;
        next_state.y = state.y + state.v * sin(state.theta) * dt;
        next_state.theta = state.theta + state.omega * dt;
        next_state.v = state.v + u.acceleration * dt;
        next_state.omega = state.omega + u.angular_acc * dt;

        return next_state;
    }
};

3.2 线性化模型

为了便于求解,通常需要在参考轨迹附近线性化非线性模型: 

// 线性化状态空间模型: x_{k+1} = A_k*x_k + B_k*u_k
class LinearizedModel {
private:
    Eigen::MatrixXd compute_A_matrix(const RobotState& ref_state, double dt) {
        Eigen::MatrixXd A = Eigen::MatrixXd::Identity(5, 5);

        // 根据雅可比矩阵计算A矩阵
        A(0, 2) = -ref_state.v * sin(ref_state.theta) * dt;
        A(0, 3) = cos(ref_state.theta) * dt;
        A(1, 2) = ref_state.v * cos(ref_state.theta) * dt;
        A(1, 3) = sin(ref_state.theta) * dt;
        A(2, 4) = dt;

        return A;
    }

    Eigen::MatrixXd compute_B_matrix(const RobotState& ref_state, double dt) {
        Eigen::MatrixXd B = Eigen::MatrixXd::Zero(5, 2);

        // 控制输入: [加速度, 角加速度]
        B(3, 0) = dt;  // v对线加速度的导数
        B(4, 1) = dt;  // ω对角加速度的导数

        return B;
    }

public:
    void linearize(const RobotState& ref_state,
                   Eigen::MatrixXd& A,
                   Eigen::MatrixXd& B,
                   double dt) {
        A = compute_A_matrix(ref_state, dt);
        B = compute_B_matrix(ref_state, dt);
    }
};

4. 代价函数设计

4.1 多目标代价函数

设计合理的代价函数是MPC成功应用的关键: 

class MPCCostFunction {
private:
    // 权重矩阵
    Eigen::MatrixXd Q_;  // 状态误差权重
    Eigen::MatrixXd R_;  // 控制输入权重
    Eigen::MatrixXd P_;  // 终端状态权重

    double w_contour_;   // 轮廓误差权重
    double w_lag_;       // 滞后误差权重
    double w_heading_;   // 航向误差权重

public:
    MPCCostFunction() {
        // 状态权重矩阵 Q
        Q_ = Eigen::MatrixXd::Zero(5, 5);
        Q_(0, 0) = 10.0;   // x位置误差
        Q_(1, 1) = 10.0;   // y位置误差
        Q_(2, 2) = 1.0;    // 航向误差
        Q_(3, 3) = 0.5;    // 速度误差
        Q_(4, 4) = 0.5;    // 角速度误差

        // 控制输入权重矩阵 R
        R_ = Eigen::MatrixXd::Zero(2, 2);
        R_(0, 0) = 0.1;    // 线加速度
        R_(1, 1) = 0.1;    // 角加速度

        // 终端权重矩阵 P (通常设为Q的较大倍数)
        P_ = 10.0 * Q_;
    }

    double compute_stage_cost(const Eigen::VectorXd& x_error,
                              const Eigen::VectorXd& u) {
        // 二次型代价: x^T*Q*x + u^T*R*u
        double state_cost = x_error.transpose() * Q_ * x_error;
        double control_cost = u.transpose() * R_ * u;

        return state_cost + control_cost;
    }

    double compute_terminal_cost(const Eigen::VectorXd& x_error) {
        return x_error.transpose() * P_ * x_error;
    }

    double compute_total_cost(const std::vector& x_traj,
                             const std::vector& u_traj,
                             const std::vector& x_ref) {
        double total_cost = 0.0;

        // 阶段代价
        for (size_t k = 0; k < u_traj.size(); ++k) {
            Eigen::VectorXd error = x_traj[k] - x_ref[k];
            total_cost += compute_stage_cost(error, u_traj[k]);
        }

        // 终端代价
        Eigen::VectorXd terminal_error = x_traj.back() - x_ref.back();
        total_cost += compute_terminal_cost(terminal_error);

        return total_cost;
    }
};

4.2 软约束处理

对于可能导致优化问题不可行的约束,可以采用软约束方法: 

// 松弛变量法处理软约束
class SoftConstraintHandler {
private:
    double slack_weight_;  // 松弛变量惩罚系数

public:
    SoftConstraintHandler(double weight = 1e6)
        : slack_weight_(weight) {}

    // 将硬约束转换为软约束
    // 例如: x_min ≤ x ≤ x_max 变为:
    // x_min - ε ≤ x ≤ x_max + ε, 代价加上 w*ε²
    double compute_slack_cost(double value,
                             double min_bound,
                             double max_bound) {
        double slack = 0.0;

        if (value < min_bound) {
            slack = min_bound - value;
        } else if (value > max_bound) {
            slack = value - max_bound;
        }

        return slack_weight_ * slack * slack;
    }
};

5. MPC求解器实现

5.1 二次规划(QP)求解

对于线性MPC,问题可转化为标准QP问题。这里使用开源库qpOASES: 

#include <qpOASES.hpp>
#include <eigen3/Eigen/Dense>

class MPCSolver {
private:
    int horizon_;          // 预测时域
    int state_dim_;        // 状态维度
    int control_dim_;      // 控制维度
    double dt_;            // 采样时间

    // QP问题矩阵
    Eigen::MatrixXd H_;    // Hessian矩阵
    Eigen::VectorXd g_;    // 梯度向量
    Eigen::MatrixXd A_cons_; // 约束矩阵
    Eigen::VectorXd lb_;   // 下界
    Eigen::VectorXd ub_;   // 上界

    void formulate_qp(const RobotState& current_state,
                     const std::vector& reference) {
        int n_vars = horizon_ * control_dim_;  // 决策变量数量

        // 构建Hessian矩阵 H 和梯度 g
        // QP形式: min 0.5*x'*H*x + g'*x
        H_.resize(n_vars, n_vars);
        g_.resize(n_vars);

        // 构建预测矩阵
        Eigen::MatrixXd S_x, S_u;
        build_prediction_matrices(current_state, reference, S_x, S_u);

        // H = 2*(S_u'*Q*S_u + R)
        H_ = 2.0 * (S_u.transpose() * Q_ * S_u + R_);

        // g = 2*S_u'*Q*(S_x*x0 - X_ref)
        Eigen::VectorXd x0 = state_to_vector(current_state);
        Eigen::VectorXd x_ref = trajectory_to_vector(reference);
        g_ = 2.0 * S_u.transpose() * Q_ * (S_x * x0 - x_ref);

        // 构建约束
        build_constraints();
    }

    void build_constraints() {
        int n_vars = horizon_ * control_dim_;

        // 控制约束: u_min ≤ u_k ≤ u_max
        lb_.resize(n_vars);
        ub_.resize(n_vars);

        for (int k = 0; k < horizon_; ++k) {
            lb_(k * control_dim_ + 0) = -2.0;  // 最小线加速度
            ub_(k * control_dim_ + 0) = 2.0;   // 最大线加速度
            lb_(k * control_dim_ + 1) = -1.0;  // 最小角加速度
            ub_(k * control_dim_ + 1) = 1.0;   // 最大角加速度
        }

        // 控制变化率约束: Δu_min ≤ u_k - u_{k-1} ≤ Δu_max
        // 这需要额外的不等式约束矩阵
    }

public:
    MPCSolver(int horizon, double dt)
        : horizon_(horizon), dt_(dt),
          state_dim_(5), control_dim_(2) {}

    std::vector solve(
        const RobotState& current_state,
        const std::vector& reference_trajectory) {

        // 1. 构建QP问题
        formulate_qp(current_state, reference_trajectory);

        // 2. 调用qpOASES求解器
        int n_vars = horizon_ * control_dim_;
        qpOASES::QProblem qp_problem(n_vars, 0);

        qpOASES::Options options;
        options.printLevel = qpOASES::PL_LOW;
        qp_problem.setOptions(options);

        // 求解
        int max_iterations = 100;
        qpOASES::returnValue ret = qp_problem.init(
            H_.data(), g_.data(),
            nullptr,  // A矩阵 (这里只有简单边界)
            lb_.data(), ub_.data(),
            nullptr, nullptr,
            max_iterations
        );

        // 3. 提取控制序列
        std::vector u_opt(n_vars);
        qp_problem.getPrimalSolution(u_opt.data());

        // 4. 转换为控制输入格式
        std::vector control_sequence;
        for (int k = 0; k < horizon_; ++k) {
            ControlInput u;
            u.acceleration = u_opt[k * control_dim_ + 0];
            u.angular_acc = u_opt[k * control_dim_ + 1];
            control_sequence.push_back(u);
        }

        return control_sequence;
    }
};

5.2 非线性MPC求解

对于非线性系统,可以使用IPOPT或CasADi等非线性优化库: 

#include <casadi/casadi.hpp>

class NonlinearMPCSolver {
private:
    casadi::Opti opti_;    // CasADi优化器
    int horizon_;
    double dt_;

    // 符号变量
    casadi::MX state_vars_;     // 状态变量 [N+1 x n_x]
    casadi::MX control_vars_;   // 控制变量 [N x n_u]

public:
    NonlinearMPCSolver(int horizon, double dt)
        : horizon_(horizon), dt_(dt) {

        // 定义优化变量
        state_vars_ = opti_.variable(5, horizon_ + 1);
        control_vars_ = opti_.variable(2, horizon_);

        // 定义参数
        casadi::MX x_init = opti_.parameter(5, 1);
        casadi::MX x_ref = opti_.parameter(5, horizon_ + 1);

        // 代价函数
        casadi::MX cost = 0;

        // 权重矩阵
        std::vector Q_diag = {10.0, 10.0, 1.0, 0.5, 0.5};
        std::vector R_diag = {0.1, 0.1};

        for (int k = 0; k < horizon_; ++k) {
            // 状态误差
            casadi::MX x_error = state_vars_(casadi::Slice(), k) -
                                x_ref(casadi::Slice(), k);

            // 阶段代价
            for (int i = 0; i < 5; ++i) {
                cost += Q_diag[i] * x_error(i) * x_error(i);
            }
            for (int i = 0; i < 2; ++i) {
                cost += R_diag[i] * control_vars_(i, k) * control_vars_(i, k);
            }

            // 动态约束
            casadi::MX x_next = nonlinear_dynamics(
                state_vars_(casadi::Slice(), k),
                control_vars_(casadi::Slice(), k)
            );
            opti_.subject_to(state_vars_(casadi::Slice(), k+1) == x_next);
        }

        // 终端代价
        casadi::MX x_terminal_error = state_vars_(casadi::Slice(), horizon_) -
                                      x_ref(casadi::Slice(), horizon_);
        for (int i = 0; i < 5; ++i) {
            cost += 10.0 * Q_diag[i] * x_terminal_error(i) * x_terminal_error(i);
        }

        // 约束
        opti_.subject_to(opti_.bounded(-2.0, control_vars_(0, casadi::Slice()), 2.0));
        opti_.subject_to(opti_.bounded(-1.0, control_vars_(1, casadi::Slice()), 1.0));
        opti_.subject_to(opti_.bounded(-1.0, state_vars_(3, casadi::Slice()), 2.0)); // 速度

        // 初始条件约束
        opti_.subject_to(state_vars_(casadi::Slice(), 0) == x_init);

        // 设置目标
        opti_.minimize(cost);

        // 求解器选项
        casadi::Dict opts;
        opts["ipopt.print_level"] = 0;
        opts["print_time"] = 0;
        opts["ipopt.max_iter"] = 100;
        opti_.solver("ipopt", opts);
    }

    casadi::MX nonlinear_dynamics(const casadi::MX& x, const casadi::MX& u) {
        // 非线性运动学模型
        casadi::MX x_next = casadi::MX::zeros(5, 1);

        x_next(0) = x(0) + x(3) * cos(x(2)) * dt_;           // x
        x_next(1) = x(1) + x(3) * sin(x(2)) * dt_;           // y
        x_next(2) = x(2) + x(4) * dt_;                       // theta
        x_next(3) = x(3) + u(0) * dt_;                       // v
        x_next(4) = x(4) + u(1) * dt_;                       // omega

        return x_next;
    }
};

6. ROS集成实现

6.1 MPC控制器节点

#include <ros/ros.h>
#include <nav_msgs/Path.h>
#include <nav_msgs/Odometry.h>
#include <geometry_msgs/Twist.h>
#include <tf2_ros/transform_listener.h>

class MPCControllerNode {
private:
    ros::NodeHandle nh_;
    ros::NodeHandle pnh_;

    // Publishers & Subscribers
    ros::Subscriber odom_sub_;
    ros::Subscriber path_sub_;
    ros::Publisher cmd_vel_pub_;
    ros::Publisher predicted_path_pub_;

    // TF
    tf2_ros::Buffer tf_buffer_;
    tf2_ros::TransformListener tf_listener_;

    // MPC配置
    int horizon_;
    double dt_;
    double control_rate_;

    // 状态
    RobotState current_state_;
    std::vector reference_trajectory_;
    bool has_path_;

    // MPC求解器
    std::unique_ptr mpc_solver_;

    void odomCallback(const nav_msgs::Odometry::ConstPtr& msg) {
        // 更新当前状态
        current_state_.x = msg->pose.pose.position.x;
        current_state_.y = msg->pose.pose.position.y;

        // 从四元数提取航向角
        tf2::Quaternion q(
            msg->pose.pose.orientation.x,
            msg->pose.pose.orientation.y,
            msg->pose.pose.orientation.z,
            msg->pose.pose.orientation.w
        );
        tf2::Matrix3x3 m(q);
        double roll, pitch, yaw;
        m.getRPY(roll, pitch, yaw);
        current_state_.theta = yaw;

        current_state_.v = msg->twist.twist.linear.x;
        current_state_.omega = msg->twist.twist.angular.z;
    }

    void pathCallback(const nav_msgs::Path::ConstPtr& msg) {
        if (msg->poses.empty()) {
            ROS_WARN("Received empty path");
            has_path_ = false;
            return;
        }

        // 转换路径为参考轨迹
        reference_trajectory_.clear();

        for (const auto& pose_stamped : msg->poses) {
            RobotState ref_state;
            ref_state.x = pose_stamped.pose.position.x;
            ref_state.y = pose_stamped.pose.position.y;

            // 提取航向角
            tf2::Quaternion q(
                pose_stamped.pose.orientation.x,
                pose_stamped.pose.orientation.y,
                pose_stamped.pose.orientation.z,
                pose_stamped.pose.orientation.w
            );
            tf2::Matrix3x3 m(q);
            double roll, pitch, yaw;
            m.getRPY(roll, pitch, yaw);
            ref_state.theta = yaw;

            reference_trajectory_.push_back(ref_state);
        }

        has_path_ = true;
        ROS_INFO("Received new reference trajectory with %lu points",
                 reference_trajectory_.size());
    }

    void controlLoop(const ros::TimerEvent& event) {
        if (!has_path_ || reference_trajectory_.empty()) {
            // 发送停止命令
            publishZeroVelocity();
            return;
        }

        // 找到最近的参考点
        int closest_idx = findClosestPoint(current_state_, reference_trajectory_);

        // 提取预测时域内的参考轨迹
        std::vector local_reference = extractLocalReference(
            closest_idx, horizon_
        );

        // 检查是否到达目标
        double dist_to_goal = hypot(
            current_state_.x - reference_trajectory_.back().x,
            current_state_.y - reference_trajectory_.back().y
        );

        if (dist_to_goal < 0.1) {
            ROS_INFO("Goal reached!");
            publishZeroVelocity();
            has_path_ = false;
            return;
        }

        // 求解MPC优化问题
        auto start_time = ros::Time::now();
        std::vector control_sequence =
            mpc_solver_->solve(current_state_, local_reference);
        auto solve_time = (ros::Time::now() - start_time).toSec();

        ROS_DEBUG("MPC solve time: %.3f ms", solve_time * 1000.0);

        // 应用第一个控制输入
        if (!control_sequence.empty()) {
            publishControl(control_sequence[0]);

            // 发布预测轨迹用于可视化
            publishPredictedPath(current_state_, control_sequence);
        } else {
            ROS_WARN("MPC solver failed to find solution");
            publishZeroVelocity();
        }
    }

    int findClosestPoint(const RobotState& current,
                        const std::vector& trajectory) {
        int closest_idx = 0;
        double min_dist = std::numeric_limits::max();

        for (size_t i = 0; i < trajectory.size(); ++i) {
            double dist = hypot(current.x - trajectory[i].x,
                              current.y - trajectory[i].y);
            if (dist < min_dist) {
                min_dist = dist;
                closest_idx = i;
            }
        }

        return closest_idx;
    }

    std::vector extractLocalReference(int start_idx, int length) {
        std::vector local_ref;

        for (int i = 0; i < length; ++i) {
            int idx = std::min(start_idx + i,
                             static_cast(reference_trajectory_.size()) - 1);
            local_ref.push_back(reference_trajectory_[idx]);
        }

        // 如果参考轨迹不够长,用最后一个点填充
        while (local_ref.size() < static_cast(length)) {
            local_ref.push_back(reference_trajectory_.back());
        }

        return local_ref;
    }

    void publishControl(const ControlInput& u) {
        // 将加速度转换为速度命令(简化版本)
        geometry_msgs::Twist cmd_vel;

        // 积分加速度得到速度(实际应该维护速度状态)
        cmd_vel.linear.x = current_state_.v + u.acceleration * dt_;
        cmd_vel.angular.z = current_state_.omega + u.angular_acc * dt_;

        // 限制速度
        cmd_vel.linear.x = std::max(-1.0, std::min(2.0, cmd_vel.linear.x));
        cmd_vel.angular.z = std::max(-1.0, std::min(1.0, cmd_vel.angular.z));

        cmd_vel_pub_.publish(cmd_vel);
    }

    void publishZeroVelocity() {
        geometry_msgs::Twist cmd_vel;
        cmd_vel.linear.x = 0.0;
        cmd_vel.angular.z = 0.0;
        cmd_vel_pub_.publish(cmd_vel);
    }

    void publishPredictedPath(const RobotState& initial_state,
                             const std::vector& controls) {
        nav_msgs::Path predicted_path;
        predicted_path.header.frame_id = "map";
        predicted_path.header.stamp = ros::Time::now();

        RobotState state = initial_state;
        KinematicModel model;

        for (const auto& u : controls) {
            state = model.predict(state, u, dt_);

            geometry_msgs::PoseStamped pose;
            pose.header = predicted_path.header;
            pose.pose.position.x = state.x;
            pose.pose.position.y = state.y;

            tf2::Quaternion q;
            q.setRPY(0, 0, state.theta);
            pose.pose.orientation.x = q.x();
            pose.pose.orientation.y = q.y();
            pose.pose.orientation.z = q.z();
            pose.pose.orientation.w = q.w();

            predicted_path.poses.push_back(pose);
        }

        predicted_path_pub_.publish(predicted_path);
    }

public:
    MPCControllerNode() : pnh_("~"), tf_listener_(tf_buffer_), has_path_(false) {
        // 加载参数
        pnh_.param("horizon", horizon_, 20);
        pnh_.param("dt", dt_, 0.1);
        pnh_.param("control_rate", control_rate_, 10.0);

        ROS_INFO("MPC Controller initialized with horizon=%d, dt=%.3f",
                 horizon_, dt_);

        // 初始化MPC求解器
        mpc_solver_ = std::make_unique(horizon_, dt_);

        // 订阅话题
        odom_sub_ = nh_.subscribe("/odom", 1,
            &MPCControllerNode::odomCallback, this);
        path_sub_ = nh_.subscribe("/reference_path", 1,
            &MPCControllerNode::pathCallback, this);

        // 发布话题
        cmd_vel_pub_ = nh_.advertise("/cmd_vel", 1);
        predicted_path_pub_ = nh_.advertise(
            "/mpc/predicted_path", 1);

        // 控制循环定时器
        ros::Timer control_timer = nh_.createTimer(
            ros::Duration(1.0 / control_rate_),
            &MPCControllerNode::controlLoop, this);

        ROS_INFO("MPC Controller node started");
    }
};

int main(int argc, char** argv) {
    ros::init(argc, argv, "mpc_controller");

    MPCControllerNode controller;
    ros::spin();

    return 0;
}

class MPCParameterTuner {
public:
    struct TuningResult {
        double tracking_error;
        double control_effort;
        double computation_time;
        double stability_margin;
    };

    TuningResult evaluate_parameters(const MPCParams& params,
                                     const TestScenario& scenario) {
        TuningResult result;

        // 1. 测试轨迹跟踪误差
        std::vector position_errors;
        std::vector heading_errors;

        for (const auto& test_point : scenario.trajectory) {
            // 运行MPC并记录误差
            RobotState predicted = run_mpc(test_point, params);
            double pos_error = compute_position_error(predicted, test_point);
            double heading_error = compute_heading_error(predicted, test_point);

            position_errors.push_back(pos_error);
            heading_errors.push_back(heading_error);
        }

        result.tracking_error = compute_rmse(position_errors);

        // 2. 测试控制输入平滑性
        result.control_effort = compute_total_control_effort();

        // 3. 测试计算时间
        result.computation_time = measure_solve_time(params);

        // 4. 评估稳定性
        result.stability_margin = analyze_closed_loop_stability(params);

        return result;
    }

    MPCParams auto_tune(const std::vector& scenarios) {
        MPCParams best_params;
        double best_score = std::numeric_limits::max();

        // 网格搜索或贝叶斯优化
        std::vector param_candidates = generate_param_grid();

        for (const auto& params : param_candidates) {
            double total_score = 0.0;

            for (const auto& scenario : scenarios) {
                TuningResult result = evaluate_parameters(params, scenario);

                // 综合评分
                double score =
                    1.0 * result.tracking_error +
                    0.1 * result.control_effort +
                    0.5 * result.computation_time -
                    0.3 * result.stability_margin;

                total_score += score;
            }

            if (total_score < best_score) {
                best_score = total_score;
                best_params = params;
            }
        }

        return best_params;
    }
};

7.3 实时性能优化

class MPCPerformanceOptimizer {
public:
    // 热启动: 使用上一次的解作为初始猜测
    void warm_start(const std::vector& previous_solution) {
        // 将上一次的解平移一步作为初始值
        std::vector initial_guess(horizon_);

        for (int k = 0; k < horizon_ - 1; ++k) {
            initial_guess[k] = previous_solution[k + 1];
        }
        // 最后一步保持不变
        initial_guess[horizon_ - 1] = previous_solution[horizon_ - 1];

        solver_->set_initial_guess(initial_guess);
    }

    // 自适应时域: 根据计算时间动态调整预测时域
    int adaptive_horizon(double available_time, double current_horizon) {
        double avg_time_per_step = measure_time_per_horizon_step();

        int max_horizon = static_cast(available_time / avg_time_per_step);

        // 限制时域变化速度
        int new_horizon = current_horizon;
        if (max_horizon < current_horizon) {
            new_horizon = std::max(10, current_horizon - 2);
        } else if (max_horizon > current_horizon + 5) {
            new_horizon = std::min(30, current_horizon + 1);
        }

        return new_horizon;
    }

    // 早停策略: 当解足够好时提前终止迭代
    bool early_stopping_criterion(double current_cost,
                                  double previous_cost,
                                  int iteration) {
        double cost_improvement = (previous_cost - current_cost) / previous_cost;

        // 如果改进小于0.1%且迭代超过5次,提前停止
        if (iteration > 5 && cost_improvement < 0.001) {
            return true;
        }

        return false;
    }
};

8. 高级话题

8.1 障碍物避障整合

class ObstacleAvoidanceMPC {
private:
    struct Obstacle {
        Eigen::Vector2d position;
        double radius;
    };

    std::vector obstacles_;
    double safety_margin_;

public:
    // 将障碍物约束加入优化问题
    void add_obstacle_constraints() {
        for (int k = 0; k < horizon_; ++k) {
            for (const auto& obs : obstacles_) {
                // 非线性约束: ||p_k - p_obs|| >= r_obs + r_robot + margin
                // 可以用CBF (Control Barrier Function) 或软约束处理

                Eigen::Vector2d pos_k(state_vars_(0, k), state_vars_(1, k));
                double dist = (pos_k - obs.position).norm();
                double min_dist = obs.radius + robot_radius_ + safety_margin_;

                // 添加软约束惩罚
                if (dist < min_dist) {
                    double violation = min_dist - dist;
                    cost += 1000.0 * violation * violation;
                }
            }
        }
    }

    // 使用控制障碍函数(CBF)保证安全性
    bool verify_safety_with_cbf(const RobotState& state,
                                const ControlInput& u) {
        for (const auto& obs : obstacles_) {
            // CBF: h(x) = ||p - p_obs||² - (r_safe)²
            double dx = state.x - obs.position.x();
            double dy = state.y - obs.position.y();
            double h = dx*dx + dy*dy - pow(obs.radius + safety_margin_, 2);

            // CBF条件: ḣ(x) + α*h(x) >= 0
            double h_dot = 2*dx*state.v*cos(state.theta) +
                          2*dy*state.v*sin(state.theta);
            double alpha = 1.0;

            if (h_dot + alpha * h < 0) {
                return false;  // 不安全
            }
        }
        return true;
    }
};

9.1 MPC优势

  • ⚠️ 模型依赖: 性能受模型精度影响
  • ⚠️ 参数调优: 需要仔细调整权重和时域
  • ⚠️ 局部最优: 非线性MPC可能陷入局部解
